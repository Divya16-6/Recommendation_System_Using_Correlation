# Anime Recommendation System using Correlation based Approach

## Overview
This project implements a recommendation system using the Correlation based Approach to recommend the anime based on the ratings of the user


## Technologies
-- **Python** - Programming Language
-- **Pandas** - Data Manipulation, Analysis and Cleaning


## Algorithm
System calculates the similarity between Animes and recommend the top similar animes to the user


## How it works?
a. User watches the anime
b. Based on the user ratings we are matching the similarity of the anime
c. It recommends the top similarities of anime to the user.
